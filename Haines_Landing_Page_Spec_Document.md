# Landing Page Specification Document
## For: Haines Products — Ad Campaign Landing Page
### Reference Analysis: SiteBoard.in Landing Page

---

## 1. OVERVIEW & OBJECTIVE

**Goal:** Build a high-converting landing page for Haines Products ad campaigns.  
**Primary Action:** Drive purchases/sign-ups/leads (define based on product).  
**Reference:** SiteBoard.in — Clean, benefit-driven, trust-building layout with strong visual hierarchy.

---

## 2. SITE STRUCTURE & SECTION FLOW

### Section 1: Hero Section (Above the Fold)
**Purpose:** Grab attention + communicate core value in 3 seconds.

| Element | Specification |
|---------|---------------|
| Headline | Bold, benefit-driven. Max 8-10 words. Example: *"The [Product] That [Solves Problem] in [Timeframe]"* |
| Subheadline | 1-2 sentences expanding the promise. Include social proof hint. |
| Primary CTA | Contrasting color button. Text: *"Shop Now / Get Yours / Claim Offer"* |
| Secondary CTA | *"Watch How It Works"* (video/lightbox) or *"See Reviews"* |
| Visual | High-quality product image or lifestyle shot. Clean background. |
| Trust Badge | Below CTA: *"Free Shipping • 30-Day Returns • 10,000+ Happy Customers"* |

**SiteBoard Reference:**
- "India's Best Real Estate CRM. Zero Chaos."
- Clear value prop + immediate CTA for pre-launch access
- Visual plot map as hero visual

---

### Section 2: Social Proof / Trust Bar
**Purpose:** Remove skepticism immediately.

| Element | Specification |
|---------|---------------|
| Client/Customer Logos | 4-6 recognizable brand logos or media mentions |
| Star Rating | Aggregate rating (e.g., "4.8/5 from 2,500+ reviews") |
| Stats Counter | "Sold 50,000+ units" or "Trusted by 10,000+ families" |

**SiteBoard Reference:**
- "Powering Sales for Modern Developers" with SKYLINE, APEX GROUP, TERRA INFRA, URBAN SPACE logos

---

### Section 3: Problem Agitation
**Purpose:** Make visitor feel the pain before offering solution.

| Element | Specification |
|---------|---------------|
| Headline | *"Tired of [Common Problem]?"* or *"Stop [Frustrating Activity]"* |
| Bullet Points | 3-4 pain points the target audience faces |
| Visual | Before/after or problem illustration |

**SiteBoard Reference:**
- "Stop managing multi-crore projects on WhatsApp and Excel"
- Pain point clearly stated before solution

| CTA | *"See Why 10,000+ People Switched"* |

## 3. DESIGN SPECIFICATIONS

### Color Palette (Reference SiteBoard)
| Role | Color | Usage |
|------|-------|-------|
| Primary | Deep Blue / Teal | Headers, CTAs, key highlights |
| Secondary | White / Light Gray | Backgrounds, cards |
| Accent | Green (success) | Available status, positive elements |
| Accent 2 | Yellow/Orange | Urgency, warnings, booked status |
| Accent 3 | Red | Sold status, sale prices, urgency |
| Text Primary | Dark Gray/Black | Body text |
| Text Secondary | Medium Gray | Captions, descriptions |

### Typography
| Element | Font Style | Size |
|---------|-----------|------|
| H1 (Hero) | Bold Sans-Serif | 48-64px |
| H2 (Section) | Bold Sans-Serif | 32-40px |
| H3 (Card Title) | Semi-Bold | 20-24px |
| Body | Regular Sans-Serif | 16-18px |
| CTA Button | Bold | 16-18px |

### Layout
- **Max Width:** 1200px centered
- **Section Padding:** 80-100px vertical
- **Card Style:** Rounded corners (8-12px), subtle shadow
- **Spacing:** Generous whitespace — don't crowd
- **Mobile:** Fully responsive, stacked sections, sticky CTA button at bottom

## 4. COPYWRITING TONE & STYLE

### Voice Characteristics
- **Confident but not arrogant:** "The best" claims backed by proof
- **Benefit-focused:** Every feature ties to a customer benefit
- **Action-oriented:** Verbs lead sentences (Stop, Save, Build, Get)
- **Simple language:** No jargon. 8th-grade reading level.
- **Urgency without pressure:** Limited offers feel genuine, not pushy

### Power Words to Use
- Zero, Instant, Exclusive, Proven, Guaranteed, Hassle-Free, Professional, Trusted, Secure, Lifetime

### SiteBoard Tone Examples to Emulate
- "Stop managing... on WhatsApp and Excel" → Direct problem callout
- "Zero Chaos" → Short, punchy benefit
- "Your data is never shared" → Reassurance
- "Anyone can instantly see" → Ease of use

## 5. TECHNICAL REQUIREMENTS

### Performance
- Page load time: < 3 seconds
- Mobile-first design
- Lazy load images below fold
- Compressed images (WebP format)

### SEO
- Meta Title: [Product] | [Key Benefit] | Haines
- Meta Description: Compelling 155-character summary
- Structured data for Product, Review, FAQ

### Tracking (For Ads)
- Facebook Pixel / Meta Pixel installed
- Google Analytics 4
- Google Ads conversion tracking
- UTM parameter support
- Heatmap tracking (Hotjar/Microsoft Clarity)

### Conversion Elements
- Sticky header with CTA on scroll
- Exit-intent popup with discount offer
- Floating "Add to Cart" / CTA button on mobile
- Social proof notifications ("Someone just bought...")

---

## 6. AD CAMPAIGN ALIGNMENT

### Landing Page Must Match Ad Creative
| Ad Element | Landing Page Match |
|------------|-------------------|
| Ad Headline | Should mirror or expand on landing page H1 |
| Ad Visual | Same product image/style as hero section |
| Ad Offer | Prominently displayed above fold |
| Ad CTA | Same button text and color |

### A/B Testing Plan
| Variant | Test Element |
|---------|-------------|
| A | Hero image: Product-only vs Lifestyle |
| B | CTA text: "Buy Now" vs "Get Yours" vs "Claim Offer" |
| C | Social proof placement: Above fold vs After features |
| D | Pricing: Show price in hero vs hide until bottom |
